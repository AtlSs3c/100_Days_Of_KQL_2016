# File and Folder Creation Under \Evelyn\Wallets\

# Description

This threat hunt detects **file and folder creation under `\AppData\...\Evelyn\Wallets\`**, an **explicit staging location** associated with **Evelyn Stealer** activity. The creation of artefacts in this directory is indicative of **wallet and credential collection**, staged locally prior to packaging or exfiltration.

# Query

```kql
DeviceFileEvents
| where Timestamp > ago(30d)
| where FolderPath has @"\AppData\"
| where FolderPath has @"\Evelyn\Wallets"
| where ActionType in~ ("FolderCreated", "FileCreated")
| project Timestamp, DeviceName, ActionType, FileName, FolderPath,
          InitiatingProcessFileName, InitiatingProcessCommandLine
